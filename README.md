# Real-Time-Stock-Market-App----Next.js-Inngest
Signalist is a stock market dashboard app built on Next.js 16 (App Router) with React 19 and TypeScript. It uses Tailwind CSS v4 and shadcn/ui (Radix primitives) for a dark-themed UI, with a header, navigation, and account/user-menu shell in place ahead of the core dashboard and market-data features.
